# TODO App

A full-stack TODO application built with an **ASP.NET Core (.NET 10) Web API** backend and an **Angular 22** frontend. Todos support categories and priorities, and are served through a clean REST API documented with Scalar/OpenAPI.

## Prerequisites

Make sure the following are installed before running the projects:

- [.NET SDK] 10.0 or later
- [Node.js] 20.x or later (LTS)
- [Angular CLI] 22.x
